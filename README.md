## 🚀 What is this?

A complete, **visually beautiful** and **feature-packed** Git & GitHub documentation page built with pure HTML, CSS & JavaScript — no frameworks, no dependencies.

Perfect for:
- 🧑‍💻 Beginners learning Git for the first time
- 📚 Students who want a quick reference
- 👨‍🏫 Teachers who want to share easy Git docs
- 💼 Developers who forget commands sometimes (we all do!)
- 🛠️ Developers who need quick tools like commit generators and error decoders

## 📋 Commands Covered

| Command | What it does |
|---|---|
| `git config` | Set your name & email |
| `git init` | Start a new repository |
| `git clone` | Download a repo from GitHub |
| `git status` | See changed files |
| `git add` | Stage files for commit |
| `git commit` | Save a snapshot |
| `git push` | Upload to GitHub |
| `git pull` | Download from GitHub |
| `git branch` | Create / list / delete branches |
| `git switch` | Switch between branches |
| `git restore` | Undo file changes |
| `git revert` | Safely undo a commit |
| `git reset` | Move HEAD to a past commit |
| `git log` | See commit history |
| `git stash` | Save work temporarily |
| `git merge` | Combine two branches |
| `git rebase` | Replay commits on top of another branch |
| `git tag` | Mark versions like v1.0 |

## ✨ Features

### 🎨 UI / UX
| Feature | Description |
|---|---|
| 🌙 **5 Color Themes** | GitHub Dark, GitHub Light, Dracula, Monokai, Nord — saved in browser |
| 📍 **Floating Sidebar** | Always-visible navigation — highlights current section while scrolling |
| 📊 **Progress Bar** | Thin bar at top shows how far down the page you've scrolled |
| 📖 **Beginner / Advanced Mode** | Toggle between simple view and full advanced examples |
| ⚖️ **Command Comparison Tool** | Compare any two Git commands side by side (e.g. `reset` vs `revert`) |
| ⌨️ **Keyboard Shortcuts** | Press `?` to see all shortcuts — navigate without touching the mouse |
| 📱 **Mobile Friendly** | Fully responsive — works great on phones and tablets |

### 📚 Content
| Feature | Description |
|---|---|
| 💡 **"Did You Know?" Tips** | 15 rotating pro Git tips shown at the top — click for the next one |
| 🕐 **Recently Viewed** | Tracks which commands you've opened — quick-access chips appear |
| 🔖 **Bookmarks Panel** | Bookmark any command — saved in browser, accessible from sidebar |
| 🔗 **Share a Command** | Copy a direct link to any specific command |
| 🔥 **Popularity Badges** | Most-viewed sections are highlighted |
| 📄 **PDF Download** | One-click PDF generation of the full cheatsheet |

### 🛠️ Interactive Developer Tools
All tools are inside the **🛠 Tools** button in the top bar:

| Tool | What it does |
|---|---|
| 💬 **Commit Message Generator** | Pick type (feat/fix/docs…), add scope & description → get a proper Conventional Commit message |
| ⚔️ **Conflict Resolver Simulator** | Paste both sides of a merge conflict, choose Accept Mine / Theirs / Both / Show Raw |
| 🚫 **.gitignore Generator** | Select project types (Node, Python, React, Django, macOS…) → instant `.gitignore` file |
| ⚡ **Git Alias Generator** | Create custom aliases → export ready `.gitconfig` snippet |
| 🔧 **Command Builder (GUI)** | Build Git commands visually using dropdowns — no typos! |
| 🐛 **Error Decoder** | Paste a Git error → get plain-English cause + exact fix |
| 🌿 **Branch Strategy Visualizer** | Interactive SVG diagrams for GitFlow, Trunk-Based, GitHub Flow |

### 🎮 Interactive Fun
| Feature | Description |
|---|---|
| 🧠 **Practice Quiz** | 10-question multiple choice quiz to test your Git knowledge |
| 🌳 **Git Tree Simulator** | Click buttons to simulate `commit`, `branch`, `merge`, `tag` — live SVG tree updates |

## 🌐 GitHub Pages (Live Website)

This project is live at:
```
https://muhammadkazim5.github.io/git-commands-cheatsheet/
```

To enable GitHub Pages on your own fork:
1. Go to repo **Settings**
2. Click **Pages** in the left sidebar
3. Set Source → Branch: `main`, Folder: `/ (root)`
4. Click **Save**
5. Wait 2–3 minutes → your site is live! 🎉
